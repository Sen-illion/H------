# 数学周末检测

## 运行方式

1. **启动后端**（在项目根目录下的 `backend` 里）  
   ```bash
   cd backend
   npm start
   ```
   后端会在 `http://localhost:3001` 运行。

2. **启动前端**（在项目根目录下的 `frontend` 里）  
   ```bash
   cd frontend
   npm run dev
   ```
   前端会在 `http://localhost:5173` 运行，在浏览器打开该地址即可。

3. **题目文档**  
   把每周的题目放在 **「周末检测」** 文件夹里，文件名为 `week_01.txt`、`week_02.txt` 等。  
   格式见下方「题目文档格式」。

## 功能说明

- **首页**：展示周次，选择某一周后点击「开始本周检测」进入做题。
- **做题页**：每题显示题号、考查知识点、题干。  
  - **填空题**：点击「作答」弹出输入框，填写后点「确认」提交该题答案。  
  - **选择题**：点击选项后，再点击「确认选择」才提交（不会点一下就提交）。  
  - **问答题**：使用「拍照 / 上传图片」选择或拍摄图片后，随整份卷子一起提交。
- **提交**：在页面顶部填写姓名/昵称，做完后点击「提交全部作答」。  
  所有答案和问答题图片会发送到后端，并保存到本地的 **「提交记录」** 文件夹。
- **老师查看**：首页底部有「老师入口：查看提交记录」，可查看每一周的提交列表、每份作答的文本和图片。

## 题目文档格式

在「周末检测」文件夹中，每个 `week_xx.txt` 按题分割，每题格式如下（**填空题**，不写题型则默认为填空）：

```
第一题
考察知识点：空集
已知集合 M={x∣2m<x<m+1}，且 M=∅，则实数 m 的取值范围是_____
答案：m≥1
解析：当区间的左端点不小于右端点时……
```

**选择题** 需要写题型，并写选项和答案：

```
第二题
题型：选择
考察知识点：集合的包含关系
题干内容...
A. 选项一
B. 选项二
C. 选项三
D. 选项四
答案：A
解析：...
```

**问答题** 需要写题型，可不写答案（由老师批改）：

```
第三题
题型：问答题
考察知识点：综合应用
题干内容...
解析：（可选）
```

## 作答数据在哪里看

- 后端会把每次提交存到项目里的 **「提交记录」** 文件夹。  
  路径：`提交记录/week_第几周/submit_时间戳/`
- 每个提交目录里有：
  - `meta.json`：姓名、提交时间、每道题的答案文本。
  - 问答题上传的图片会保存在同一目录下。
- 你也可以在前端打开「老师入口：查看提交记录」页面，按周次查看每份提交的作答和图片。

## 让弟弟在自己设备上打开链接使用

- **发布到 GitHub 生成可玩链接（推荐）**：把项目推到 GitHub，用 [Render](https://render.com) 连接仓库一键部署，会得到一个**直接能玩的链接**（如 `https://xxx.onrender.com`），弟弟和你打开即可用。详见 **[DEPLOY.md](DEPLOY.md)** 的「方式一」。
- **同一 WiFi**：弟弟用浏览器打开 `http://你的电脑IP:5173`（你电脑需先运行前后端）。查 IP：Windows 在 CMD 输入 `ipconfig` 看 IPv4。
- **自己的云服务器**：部署到一台服务器，用固定链接访问。详见 **[DEPLOY.md](DEPLOY.md)** 的「方式三」。
